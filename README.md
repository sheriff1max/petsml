# Pets-ML

## <a href='/base-agent/'>base-agent</a>

О проекте: Минималистичный tool-calling агент, написанный с нуля без сторонних зависимостей. Запустить можно как на маленькой локальной модели через OllamaLLM / OpenAILLM, так и через API.

Стек: Python, OllamaLLM / OpenAILLM API

Что сделано: работающий агент с выбором модели. Работать с LLM можно как локально, так и через API с использованием API_KEY. Для агента реализованы следующие инструменты: калькулятор, считывание файла, переход по URL и получение тела страница. Шаги агента логируются. Количество шагов работы агента можно регулировать.
